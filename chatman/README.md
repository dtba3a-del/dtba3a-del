# chatman

Стенограммы рабочих чатов, поиск с замером покрытия, канон работы.
Один файл, ставится один раз, работает в любом проекте и в любом чате.

## Зачем

Контекст чата сжимается по мере роста, а решения принимаются именно там,
в подробностях, которые первыми и вымываются. `chatman` выгружает
стенограмму **дословно**, ищет по ней и по корпусу файлов проекта, и
держит перед глазами канон работы.

Три вещи, ради которых он написан:

* **Дословность.** `chatlog/raw/*.jsonl` — источник истины, ничего не
  переписывается и не «причёсывается». Рядом лежит `manifest.json` с
  границами кусков и `sha256`, так что запись проверяема.
* **Врезки.** Часть распоряжений приходит не отдельным ходом, а очередью
  внутрь уже идущего (`attachment.type="queued_command"`). Читалка, не
  знающая о них, теряет их молча: замер по одному репозиторию дал 14
  распоряжений из 22 — 8 врезок (36 %) были невидимы, и среди них самые
  весомые поправки разговора.
* **Отсутствие утечки между проектами.** Стенограммы всех проектов лежат
  в одном каталоге профиля. Отбор идёт не по имени каталога, а по полю
  `cwd` внутри самих записей: в репозиторий проекта попадают только его
  собственные стенограммы. Снять ограничение можно, но только явно —
  ключом `--all-projects`.

Общего каталога логов нет и он не нужен: записи уже лежат в профиле
(`~/.claude/projects/`), в приватной зоне, и инструмент читает их там, на
месте. `find`, `search`, `repos` выгрузки не требуют и ничего никуда не
копируют.

## Установка

```bash
python3 chatman.py install     # ~/.claude/tools + ~/.local/bin + навык
chatman doctor                 # самопроверка
```

В новом проекте — один раз:

```bash
cd <корень проекта> && chatman init
```

Заводит `.chatman/rules.md` (канон этого проекта), `.chatman/config.json`
и `.chatman/README.md` — указатель сюда, чтобы проект был осведомлён о
наличии инструмента явно, без копии инструмента внутри себя.

## Порядок применения

```bash
chatman repos                           # какие репозитории есть в профиле
chatman find --prompts --grep '...'     # найти распоряжение
chatman find --context 77 --around 3    # что было вокруг него
chatman find --repo Oscill --prompts    # заглянуть в другой свой проект
chatman search Ричардсон --fuzzy 1      # поиск по корпусу с замером
chatman rules                           # канон: общий + проектный
chatman export                          # выгрузить стенограмму в репозиторий
```

`export` — осознанное действие: он публикует дословную запись в тот
репозиторий, где запущен. Осмысленно для приватного репозитория; для
публичного команда предупреждает отдельно.

## Правила пользования

**Полное описание — в докстринге самого файла.** Он и есть руководство;
отдельного документа, который может разойтись с кодом, намеренно нет.

```bash
head -110 chatman.py
```

## Требования

Python 3.9+, стандартная библиотека. Внешних зависимостей нет.
